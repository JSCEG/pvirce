Liga pública para envío por correo

Formulario institucional para participantes

Esta propuesta está pensada para distribuirse como una liga única por correo, conservar la identidad visual institucional y registrar las respuestas en Google Sheets con un control de duplicados desde origen.

Evita registros repetidos Llave única por evento + correo electrónico, con revisión previa antes de guardar.
Conectable a Google Sheets Puede enviar a Apps Script o a un endpoint intermedio y escribir directo en una hoja.
Con preloader y estados La pantalla de carga y los mensajes de confirmación ya quedan integrados.
Listo para móvil El formulario está preparado para abrirse bien desde teléfonos y correo.

Ruta propuesta

1. Liga pública

Una sola URL para compartir por correo, con branding SENER y mensaje de contexto.

2. Validación antes del guardado

El cliente envía nombre, correo y una clave compuesta `evento + correo normalizado`.

3. Escritura controlada en Sheets

Apps Script revisa si la llave ya existe; si existe rechaza, si no existe inserta y devuelve folio.

4. Confirmación rastreable

Se regresa un folio visible para el participante y queda guardado con marca de tiempo.

Formulario base

Registro de asistencia

Ajusta los campos finales según el evento y conecta la constante de envío a la hoja correspondiente. Esta versión ya sirve como propuesta visual y funcional.

Se propone usar este campo como identificador principal para evitar duplicados.
Propuesta técnica: escribir en Google Sheets mediante Apps Script con revisión previa de llave única.

Registro enviado

La interfaz muestra una confirmación clara y devuelve un folio que puede reutilizarse en el correo de confirmación.

Folio:

Si el endpoint detecta que el correo ya fue registrado para el mismo evento, el formulario muestra un rechazo controlado y no inserta una fila nueva.

Control de duplicados

Llave por evento Correo normalizado Revisión en servidor

La mejor opción no es bloquear solo en navegador, sino generar una clave única con el formato `EVENTO|correo@dominio` y verificarla antes de escribir en la hoja.

Además de eso, esta propuesta agrega un bloqueo local para evitar doble clic o reenvío inmediato desde el mismo navegador.

Estructura sugerida en Google Sheets

  • `timestamp` para marca de tiempo del alta.
  • `folio` para referencia visible al participante.
  • `eventId` para separar eventos o convocatorias.
  • `dedupeKey` como campo de control no editable.
  • Campos de negocio: nombre, institución, cargo, correo, teléfono, modalidad y comentarios.

Siguiente conexión

En cuanto compartas la liga del archivo de Google Sheets o la estructura de columnas, se puede amarrar el formulario a un Apps Script con respuesta JSON y dejarlo operando sobre la hoja real.

La constante `APPS_SCRIPT_URL` en este archivo es el punto de conexión pensado para eso.
